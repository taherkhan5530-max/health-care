# Total Care Health — Homepage

Modern, clean, and responsive healthcare website homepage for Total Care Health.

## What is in this repo

- `index.html` — the complete homepage, self-contained.
  - Navigation: TOTAL CARE HEALTH, Home (active), About, Services, Employers, Patient Login, Learn more
  - Hero: "Meet Your New Team Doctors", "24/7 dedicated access to concierge care from board-certified physicians.", Get in Touch
  - Doctor photo in a large circular frame, with dot-grid and yellow semi-circle accents
  - Partner logo strip

All images and logos are inlined in `index.html`, so the page works by opening that one file — no separate asset files are needed.

## View it

Open `index.html` in a browser, or serve the folder with any static web server.
